## Problems Solved

1. **multiplyValue**: multiplies a number by a multiplier (default `2`).
2. **processInput**: handles `string | number | boolean` input using type narrowing.
3. **formatCoordinate**: formats a readonly tuple `[latitude, longitude, name]`.
4. **concatenateArrays**: a generic function that merges any number of arrays.
5. **getPopularCourses**: filters published courses that meet a minimum student count.
6. **pluckValues**: a generic function that picks one property from every item using `keyof`.
7. **Employee / Manager**: classes with inheritance and `protected`/`private` access modifiers.
8. **validateAgeAsync**: an async function that returns a `Promise`, resolving or rejecting based on age.
